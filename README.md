# AI Infrastructure Forensics

Public research companion to Kilambi Research's forensic investigation into how the AI datacenter buildout is financed: off-balance-sheet structures, SPVs, leases, and counterparties.

## Structure
- `sites/` — site-by-site analyses (entity chains, tenants, lenders, permits, power, local records)
- `county-records/` — county clerk/appraisal reconnaissance and deed pulls
- `cloud-buckets/` — public cloud-storage OSINT sweeps
- `timeline/` — lease and financing timeline analysis
- `known-unknowns.md` — what we looked for and could not find (nulls are findings)
- `paper/` — the working paper, when built

All material is from publicly accessible sources. Nothing here is investment advice.
